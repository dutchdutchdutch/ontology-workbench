# BIS-14 Customer record keeps phone number from booking

Team: BIS · Reporter: Priya · Labels: booking, data · Status: Done

## Description

Customer record keeps the phone number from the booking, so the host can text the party when
their table is ready. One customer record per phone number. Covers is the party size on the
booking, not a separate count.

## Comments

Theo: Careful. Covers is not party size. Covers is how many guests actually sat down. A booking
for six where five turn up is five covers.
